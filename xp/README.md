# 供应商结算导入校验（第二阶段）

需要 Java 21。首次构建需联网下载 Maven 依赖。

```powershell
.\mvnw.cmd spring-boot:run
```

访问 http://localhost:8080 。选择或拖拽 `.xlsx` 后点击“上传并校验”。

## 运营修正流程

1. 选择工作表，分别查看“待修正”和“校验通过”列表，两组独立展示且每页100条。
2. 待修正列表高亮错误单元格，并显示字段与原因；左侧行号始终对应 Excel 原始行号，跳过空行后不会重新编号。
3. 点击“导出全部错误（Word）”，下载真正的 `.docx` 文件，包含所有可见工作表的错误，不受当前选择的组别、工作表或分页影响。报告包含源文件名、汇总、工作表名、Excel行号、单元格、字段、当前显示值和原因，同一行多个问题分开列出。
4. 在原 Excel 中修改并保存，点击“修正后重新上传”，选择修改后的文件，再点击“上传并校验”。系统完整重新校验，不沿用上一次结果。当前修正方式为修改 Excel 后重新上传，页面不直接编辑单元格。

## 字段规则

每张可见工作表首个非空行为表头，按名称识别列，列顺序可调整。前六列名称必须存在，备注列可省略：

- 供应商名称：必填，不能纯空白。
- 统一社会信用代码：必填，18位数字和大写字母，排除 I/O/Z/S/V。
- 联系人：必填。
- 手机号：必填，11位数字，以1开头。
- 结算金额：必填，数字且非负。校验原始数值，避免显示格式舍入隐藏负数。文本金额不接受货币符号或千分位文字。
- 合作开始日期：必填，真实存在的日期；支持 Excel 日期和 yyyy-M-d、yyyy/M/d、yyyy年M月d日 文本。
- 备注：选填。

字段两端空白忽略。必填字段中的公式需转成实际值；公式不执行。信用代码在所有可见工作表间查重，重复的所有数据行都列入待修正。缺少或重复表头时，该工作表所有数据行都列入待修正；仅有表头也会报告无数据。

## 边界与接口

- 文件最大10 MB，总非空行数（含表头）最多10000行，每行最多200列。
- 仅解析校验，不写入数据库。数据库已有供应商查重尚未接入，不能据字段校验通过确认入库。
- “金额合理”尚无业务阈值，暂不限制金额上限或小数位数。
- `POST /api/preview`，multipart字段 `file`：返回预览、每张表的 validRows / invalidRows / headerIssues，以及校验汇总。
- `POST /api/errors/word`，multipart字段 `file`：服务器重新解析校验原文件，返回Word附件；没有错误时返回可读提示。上传数据在内存内处理，不持久保存。

测试：`.\mvnw.cmd test`
